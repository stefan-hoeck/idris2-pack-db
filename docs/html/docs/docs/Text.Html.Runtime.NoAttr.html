Text.Html.Runtime.NoAttr

(source)
Runtime HTML elements constructors without "either_" prefix nor attributes.

All those constructors return an `Either` type where the:

- `Left` value is a message in case of error; and
- the `Right` value a list with, as single item, the resulting element.
