  Escaped attribute value.
  
  The constructor is not exported. Escaped attribute values can only be
  created using the `escape` function.

escape : String -> EscapedValue
  Escapes a string for use as an attribute value.
  
  The following characters are escaped: '"', '\'', '&' and '<'.
  This function is the only way to construct an `EscapedValue` as the
  `EscapedValue` constructor is kept private.
