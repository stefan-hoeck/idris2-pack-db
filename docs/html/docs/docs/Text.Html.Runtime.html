Text.Html.Runtime

(source)
Runtime HTML elements constructors without "either_" prefix.

Use this flavour if you want all test validation checks to be carried out
carried out at runtime.

All those constructors return an `Either` type where the:

- `Left` value is a message in case of error; and
- the `Right` value a list with, as single item, the resulting element.
