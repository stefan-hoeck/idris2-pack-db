Text.Html.Attributes

(source)
HTML element attributes.

The below methods require for their values data types which can be obtained
using strings as they all implement a `fromString` function.

Those `fromString` functions are rather restrictive in terms of accepted
values. The aim is to only accept values which aren't only compliant with
standards but also with best practices.

If needed, you can bypass such requirements using their constructors.
For example, you could use `MkId` if you need to use an identifier which
would need escaping for CSS.

id : Identifier -> Attribute
  An **id** attribute.
  
  An identifier must be a valid CSS selectors which doesn't need escaping as
  per [MDN's recommendations][1]
  
  An identifier must be composed only of alphanumerical characters, '-' or
  '_'.
  
  On top of the above, an identifer must not:
  
  - start with a digit or with a '-';
  
  (The above is a small simplification, as the actual rule is that an
  identifier cannot start with a '-' followed by a digit.)
  
  [1]: https://developer.mozilla.org/docs/Web/HTML/Reference/Global_attributes/id
