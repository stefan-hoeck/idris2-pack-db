identifier : String -> Either String Identifier
  Creates a valid CSS identifier.
  
  The approach is restrictive, so such identifier is valid in Javascript.
  Consequently, only the character set [A-Za-z0-9-_] is accepted.
  On top of the above, an identifier cannot start with a digit nor with
  an hyphen.
  Also, an identifier cannot be empty.
  
  Note that you can still create an identifier outside of the above
  restrictions using the `MkIdentifier`.
