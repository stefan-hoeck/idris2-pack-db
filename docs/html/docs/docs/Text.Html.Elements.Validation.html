Text.Html.Elements.Validation

(source)
Collection of validation functions for HTML elements.

All these methodes return an `Either` data type.
If there are no errors, the provided input is returnd unchanged as `Right`
value.
If there is an error, an error message is returned as `Left` value.

  Validates a **video** element.
  
  If the **video** element has a **src** attribute, accepts:
  
  - zero or more **source** elements; and then
