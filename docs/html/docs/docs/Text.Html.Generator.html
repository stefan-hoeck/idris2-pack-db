Text.Html.Generator

(source)
HTML code generator.

This module offers functions to convert a `Html` type to a string.
The two main functions are:

- `genHtml`: which renders the HTML on multiple lines with an indentation
   of two spaces for each level of the HTML tree to ensure good readability;
   and
- `genHtmlMin`: which renders the HTML on one single line to minify the
   output.

Alternatively, you can provide your own configuration to the `genHtmlConf`
function. This allows to use tabs instead of spaces or to set your own
indentation, such as four spaces for example.

For convenience, the below functions are also exported, in case you would
like to render a particular attribute or element:

- `genAttribute`
- `genElement`

Note that you will need to provide your own configuration and, for
`genElement`, provide the indentation.
